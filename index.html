swbrd

Reduced-signalling peer-to-peer WebRTC. The library lives in src/; the servers it talks to are the daemons in crates/, deployed at turn.evan-brass.net.

Test pages

Each page drives one scenario and reports a verdict, both into the page and as a SWBRD-RESULT console line. Open one here, or run it headless and get the matching server logs back with ./scripts/dev.sh e2e tests/<page> --units=<unit>.

  • vpn.html — Conn.to_deter() into the SCTP/DataChannel VPN. Server side: dtls-proxy, swbrd.
  • p2p.html — two Conns connecting to each other through the relay. Server side: turnserver.
  • soak.html — a relayed pair held open across TURN refreshes (?hold= seconds), for breakage that only shows up after the connection is already up. Server side: turnserver.
  • audio.html — the fixed opus / telephone-event m-section with a microphone attached. Server side: dtls-proxy.
  • icmp.html — traffic at an unallocated relay address; the assertion is in the turnserver journal, not the browser.
  • relay.html — stock RTCPeerConnection with munged ICE credentials. Server side: ice-dissolve. Legacy: Chrome is removing credential munging, so this one is expected to stop working.
